# Viral Coefficient and K-Factor Analysis

## Overview

Viral growth occurs when existing users bring in new users, creating a self-sustaining growth loop. The viral coefficient (K-factor) measures how many new users each existing user generates. Understanding and optimizing virality is crucial for achieving exponential, low-cost growth.

**Key Capabilities:**
- K-factor (viral coefficient) calculation
- Viral cycle time measurement
- Referral program analysis
- Viral loop modeling and simulation
- Branching factor analysis
- Growth rate decomposition (organic vs. paid vs. viral)
- Viral optimization recommendations

Use this skill when:

- Modeling exponential growth scenarios
- Identifying viral bottlenecks

- Forecasting viral-driven user acquisition

### 1. Basic K-Factor Calculation

Calculate the viral coefficient.

```python
import pandas as pd
import numpy as np
from datetime import datetime, timedelta

def calculate_k_factor(
    invitations_sent: int,
    users_who_invited: int,
    signups_from_invitations: int,
    total_new_users: int
) -> dict:
    """
    Calculate viral coefficient (K-factor).

    K-factor = (% users who invite) × (invitations per user) × (conversion rate)

    Parameters:
    -----------
    invitations_sent : Total invitations sent
    users_who_invited : Number of users who sent invitations
    signups_from_invitations : New users from invitations
    total_new_users : Total new users in period

    Returns:
    --------
    dict with viral metrics
    """
    # Invitation rate (% of users who invite)
    # Note: Need total users for accurate rate
    # For now, use users_who_invited as proxy

    # Invitations per inviting user
    invitations_per_user = invitations_sent / users_who_invited if users_who_invited > 0 else 0

    # Conversion rate (invitations -> signups)
    conversion_rate = signups_from_invitations / invitations_sent if invitations_sent > 0 else 0

    # K-factor (simplified: invitations per user × conversion rate)
    k_factor = invitations_per_user * conversion_rate

    # Viral contribution to growth
    viral_contribution_pct = (
        signups_from_invitations / total_new_users * 100 if total_new_users > 0 else 0
    )

    return {
        'invitations_sent': invitations_sent,
        'users_who_invited': users_who_invited,
        'invitations_per_inviting_user': invitations_per_user,
        'signups_from_invitations': signups_from_invitations,
        'conversion_rate': conversion_rate,
        'k_factor': k_factor,
        'viral_contribution_pct': viral_contribution_pct
    }

# Example: Calculate K-factor
k_metrics = calculate_k_factor(
    invitations_sent=10000,
    users_who_invited=500,
    signups_from_invitations=1500,
    total_new_users=5000
)

print("Viral Coefficient (K-Factor) Analysis:")
print(f"Invitations sent: {k_metrics['invitations_sent']:,}")
print(f"Users who invited: {k_metrics['users_who_invited']:,}")
print(f"Invitations per inviting user: {k_metrics['invitations_per_inviting_user']:.1f}")
print(f"Signups from invitations: {k_metrics['signups_from_invitations']:,}")
print(f"Conversion rate: {k_metrics['conversion_rate']:.1%}")
print(f"K-factor: {k_metrics['k_factor']:.3f}")
print(f"Viral contribution to growth: {k_metrics['viral_contribution_pct']:.1f}%")

if k_metrics['k_factor'] > 1:
    print("\n✓ K-factor > 1: Viral growth! Each user brings more than 1 new user.")
elif k_metrics['k_factor'] > 0.5:
    print("\n✓ K-factor > 0.5: Strong viral coefficient, significant organic growth.")
else:
    print("\n⚠ K-factor < 0.5: Limited viral growth, focus on optimization.")
```

### 2. Detailed K-Factor with Viral Cycle

Calculate K-factor with time component.

```python
def calculate_detailed_k_factor(
    df: pd.DataFrame,
    user_col: str = 'user_id',
    invite_col: str = 'invitations_sent',
    signup_col: str = 'referred_signups',
    cohort_date_col: str = 'cohort_date',
    total_users_in_cohort: int = None
) -> pd.DataFrame:
    """
    Calculate detailed K-factor by cohort with time dynamics.

    Parameters:
    -----------
    df : DataFrame with user invitation and referral data
    user_col : User identifier
    invite_col : Number of invitations sent
    signup_col : Signups generated by user
    cohort_date_col : User cohort date
    total_users_in_cohort : Total users in each cohort

    Returns:
    --------
    DataFrame with K-factor by cohort
    """
    df = df.copy()
    df[cohort_date_col] = pd.to_datetime(df[cohort_date_col])

    # Create cohort period
    df['cohort_period'] = df[cohort_date_col].dt.to_period('M')

    # Aggregate by cohort
    cohort_viral = df.groupby('cohort_period').agg({
        user_col: 'count',
        invite_col: 'sum',
        signup_col: 'sum'
    }).reset_index()

    cohort_viral.columns = [
        'cohort_period', 'total_users', 'total_invitations', 'total_referrals'
    ]

    # Calculate metrics
    cohort_viral['invitations_per_user'] = (
        cohort_viral['total_invitations'] / cohort_viral['total_users']
    )

    cohort_viral['conversion_rate'] = (
        cohort_viral['total_referrals'] / cohort_viral['total_invitations']
    )

    cohort_viral['k_factor'] = (
        cohort_viral['invitations_per_user'] * cohort_viral['conversion_rate']
    )

    # Virality type
    cohort_viral['virality_type'] = cohort_viral['k_factor'].apply(
        lambda k: 'Viral (K>1)' if k > 1
        else 'Sub-viral but strong (K>0.5)' if k > 0.5
        else 'Limited viral (K<0.5)'
    )

    return cohort_viral

# Example: Generate referral data
np.random.seed(42)

# Create user cohorts with referral activity
n_users = 2000
referral_data = []

for user_id in range(n_users):
    cohort_date = pd.Timestamp('2023-01-01') + pd.Timedelta(
        days=np.random.randint(0, 365)
    )

    # Some users invite, others don't
    if np.random.random() < 0.3:  # 30% of users send invites
        invitations_sent = np.random.randint(1, 20)

        # Conversion rate varies
        conversion_rate = np.random.beta(2, 5)  # Average ~0.2
        referred_signups = np.random.binomial(invitations_sent, conversion_rate)
    else:
        invitations_sent = 0
        referred_signups = 0

    referral_data.append({
        'user_id': user_id,
        'cohort_date': cohort_date,
        'invitations_sent': invitations_sent,
        'referred_signups': referred_signups
    })

referral_df = pd.DataFrame(referral_data)

# Calculate detailed K-factor
detailed_k = calculate_detailed_k_factor(referral_df)

print("\nK-Factor by Cohort:")
print(detailed_k.to_string(index=False))
```

### 3. Viral Cycle Time

Measure how long it takes for viral loop to complete.

```python
def calculate_viral_cycle_time(
    df: pd.DataFrame,
    user_col: str = 'user_id',
    invite_date_col: str = 'invite_sent_date',
    signup_date_col: str = 'referred_signup_date'
) -> dict:
    """
    Calculate viral cycle time (time from invite to signup).

    Parameters:
    -----------
    df : DataFrame with invitation and signup dates
    user_col : User identifier
    invite_date_col : Date invitation was sent
    signup_date_col : Date referred user signed up

    Returns:
    --------
    dict with cycle time metrics
    """
    df = df.copy()
    df[invite_date_col] = pd.to_datetime(df[invite_date_col])
    df[signup_date_col] = pd.to_datetime(df[signup_date_col])

    # Calculate time from invite to signup
    df['cycle_time_days'] = (
        df[signup_date_col] - df[invite_date_col]
    ).dt.days

    # Remove negative or very long cycles (data quality)
    df_clean = df[(df['cycle_time_days'] >= 0) & (df['cycle_time_days'] <= 90)]

    # Calculate statistics
    cycle_metrics = {
        'mean_cycle_time_days': df_clean['cycle_time_days'].mean(),
        'median_cycle_time_days': df_clean['cycle_time_days'].median(),
        'p25_cycle_time_days': df_clean['cycle_time_days'].quantile(0.25),
        'p75_cycle_time_days': df_clean['cycle_time_days'].quantile(0.75),
        'p90_cycle_time_days': df_clean['cycle_time_days'].quantile(0.90),
        'total_conversions': len(df_clean)
    }

    print("\nViral Cycle Time Analysis:")
    print(f"Total conversions: {cycle_metrics['total_conversions']:,}")
    print(f"Mean cycle time: {cycle_metrics['mean_cycle_time_days']:.1f} days")
    print(f"Median cycle time: {cycle_metrics['median_cycle_time_days']:.1f} days")
    print(f"25th percentile: {cycle_metrics['p25_cycle_time_days']:.1f} days")
    print(f"75th percentile: {cycle_metrics['p75_cycle_time_days']:.1f} days")
    print(f"90th percentile: {cycle_metrics['p90_cycle_time_days']:.1f} days")

    return cycle_metrics, df_clean

# Example: Generate cycle time data
invite_signup_data = []

for _, row in referral_df[referral_df['referred_signups'] > 0].iterrows():
    # For each referred signup, create an invite-signup pair
    for _ in range(int(row['referred_signups'])):
        invite_date = row['cohort_date'] + pd.Timedelta(
            days=np.random.randint(0, 60)
        )

        # Cycle time (invite to signup)
        cycle_time = np.random.gamma(2, 3)  # Average ~6 days

        signup_date = invite_date + pd.Timedelta(days=cycle_time)

        invite_signup_data.append({
            'inviter_id': row['user_id'],
            'invite_sent_date': invite_date,
            'referred_signup_date': signup_date
        })

invite_signup_df = pd.DataFrame(invite_signup_data)

# Calculate cycle time
cycle_metrics, cycle_data = calculate_viral_cycle_time(invite_signup_df)
```

### 4. Viral Growth Modeling

Model viral growth over time.

```python
def model_viral_growth(
    initial_users: int,
    k_factor: float,
    cycle_time_days: float,
    time_periods: int = 100,
    churn_rate_per_period: float = 0.0
) -> pd.DataFrame:
    """
    Model viral growth over time.

    Parameters:
    -----------
    initial_users : Starting number of users
    k_factor : Viral coefficient
    cycle_time_days : Days for one viral cycle
    time_periods : Number of periods to simulate
    churn_rate_per_period : Churn rate per period

    Returns:
    --------
    DataFrame with growth projections
    """
    growth_data = []

    current_users = initial_users

    for period in range(time_periods):
        # New users from viral growth
        new_viral_users = current_users * k_factor

        # Churned users
        churned_users = current_users * churn_rate_per_period

        # Net growth
        net_new_users = new_viral_users - churned_users
        current_users = current_users + net_new_users

        # Calculate growth rate
        growth_rate = (net_new_users / (current_users - net_new_users) * 100
                      if current_users > net_new_users else 0)

        growth_data.append({
            'period': period,
            'total_users': current_users,
            'new_viral_users': new_viral_users,
            'churned_users': churned_users,
            'net_growth': net_new_users,
            'growth_rate_pct': growth_rate
        })

    return pd.DataFrame(growth_data)
```

### 6. Viral Funnel Analysis

Analyze the referral funnel to identify drop-offs.

```python
def analyze_viral_funnel(
    total_users: int,
    users_who_saw_referral: int,
    users_who_clicked: int,
    users_who_invited: int,
    invitations_sent: int,
    signups_from_invitations: int
) -> dict:
    """
    Analyze viral funnel conversion rates.

    Funnel steps:
    1. User sees referral option
    2. User clicks referral option
    3. User sends invitation
    4. Invitation is sent
    5. Invitee signs up

    Parameters:
    -----------
    Various funnel metrics

    Returns:
    --------
    dict with funnel analysis
    """
    funnel = {
        'total_users': total_users,
        'saw_referral': users_who_saw_referral,
        'clicked': users_who_clicked,
        'invited': users_who_invited,
        'invitations_sent': invitations_sent,
        'signups': signups_from_invitations
    }

    # Calculate conversion rates
    conversion_rates = {
        'saw_to_clicked': users_who_clicked / users_who_saw_referral * 100
        if users_who_saw_referral > 0 else 0,

        'clicked_to_invited': users_who_invited / users_who_clicked * 100
        if users_who_clicked > 0 else 0,

        'invitations_per_inviter': invitations_sent / users_who_invited
        if users_who_invited > 0 else 0,

        'invite_to_signup': signups_from_invitations / invitations_sent * 100
        if invitations_sent > 0 else 0,

        'overall_conversion': signups_from_invitations / total_users * 100
        if total_users > 0 else 0
    }

    # Identify biggest drop-offs
    funnel_steps = [
        ('Total Users', total_users),
        ('Saw Referral', users_who_saw_referral),
        ('Clicked', users_who_clicked),
        ('Sent Invites', users_who_invited),
        ('Invitations Sent', invitations_sent),
        ('Signups', signups_from_invitations)
    ]

    drop_offs = []
    for i in range(len(funnel_steps) - 1):
        step_name, step_count = funnel_steps[i]
        next_step_name, next_step_count = funnel_steps[i + 1]

        drop_off_pct = (step_count - next_step_count) / step_count * 100 if step_count > 0 else 0

        drop_offs.append({
            'from_step': step_name,
            'to_step': next_step_name,
            'drop_off_pct': drop_off_pct
        })

    return {
        'funnel': funnel,
        'conversion_rates': conversion_rates,
        'drop_offs': drop_offs
    }

# Example: Analyze viral funnel
viral_funnel_analysis = analyze_viral_funnel(
    total_users=10000,
    users_who_saw_referral=8000,  # 80% saw it
    users_who_clicked=2000,  # 25% clicked
    users_who_invited=500,  # 25% of clickers invited
    invitations_sent=10000,  # 20 invites per inviter
    signups_from_invitations=1500  # 15% conversion
)

print("\nViral Funnel Analysis:")
print("\nFunnel Metrics:")
for key, value in viral_funnel_analysis['funnel'].items():
    print(f"  {key}: {value:,}")

print("\nConversion Rates:")
for key, value in viral_funnel_analysis['conversion_rates'].items():
    if 'per' in key:
        print(f"  {key}: {value:.1f}")
    else:
        print(f"  {key}: {value:.1f}%")

print("\nBiggest Drop-offs:")
drop_offs_df = pd.DataFrame(viral_funnel_analysis['drop_offs'])
print(drop_offs_df.sort_values('drop_off_pct', ascending=False).to_string(index=False))
```

## Best Practices

### 1. K-Factor Targets
- **K > 1**: Viral growth (exponential)
- **K = 0.5-1**: Strong viral component, but not self-sustaining
- **K = 0.2-0.5**: Modest viral contribution
- **K < 0.2**: Limited viral growth

### 2. Optimization Levers
- **Invitation rate**: Get more users to invite
- **Invitations per user**: Make it easier to invite many people
- **Conversion rate**: Improve invitation experience and landing page
- **Cycle time**: Reduce time from invite to signup

### 3. Referral Program Design
- **Two-sided incentives**: Reward both referrer and referee
- **Easy sharing**: Reduce friction in invitation process
- **Trust signals**: Use social proof, testimonials
- **Tracking**: Attribute signups correctly to referrers

### 4. Common Pitfalls to Avoid
- **Gaming/fraud**: Monitor for fake referrals
- **Spam**: Don't encourage users to spam contacts
- **Poor targeting**: Quality > quantity of invitations
- **Weak value prop**: Product must be worth referring

### 5. Measurement
- **Track cohorts**: K-factor changes over time and by cohort
- **Segment analysis**: Different user types have different K-factors
- **Channel attribution**: Track referral sources
- **Long-term value**: Referred users may behave differently
